Art direction / recreation prompt: A polished editorial technology visual on deep graphite, a luminous glass core surrounded by separated translucent orbital harness rings, mint and restrained amber illumination, elegant dimensional depth, subtle atmospheric glow, generous quiet space on the left for presentation typography, main object on the right, no words, no logos. Wide presentation composition. This records the visual direction for recreation, rather than claiming an exact byte-for-byte generation prompt.

UI visuals are implemented in local HTML/CSS/JavaScript. Stage changes, code-line reveals, model activity, and trace arrivals animate; the interface includes reduced motion. The slide deck uses native fade transitions and selected click builds. Native PowerPoint playback should be rehearsed on the presentation machine.
